### 2. フラッシュカード一覧 `/flashcards`

**目的**: 学習するカードセットの選択と管理

```
┌─────────────────────────────────────────────────────┐
│  フラッシュカード              [+ 新規作成]         │
├─────────────────────────────────────────────────────┤
│  [LPIC-1] [LPIC-2] [応用情報]  ← 資格タブ          │
├─────────────────────────────────────────────────────┤
│  分野                    枚数   操作                │
│  ─────────────────────────────────────────────     │
│  ファイル操作            15枚  [学習] [編集]        │
│  プロセス管理            12枚  [学習] [編集]        │
│  ネットワーク設定        20枚  [学習] [編集]        │
│  テキスト処理            8枚   [学習] [編集]        │
│  ─────────────────────────────────────────────     │
│  全分野まとめて         55枚  [学習開始]            │
└─────────────────────────────────────────────────────┘
```

**操作**
- 資格タブ切り替え → 対応する分野一覧を表示
- `[学習]` → 学習モード画面へ（該当分野のカードのみ）
- `[全分野まとめて 学習開始]` → 現在の資格タブ全カードで学習
- `[+ 新規作成]` → カード作成画面へ

### 3. フラッシュカード学習 `/flashcards/study`

**目的**: カードをめくりながら暗記する

```
┌─────────────────────────────────────────────────────┐
│  LPIC-1 > ファイル操作          [× 終了]           │
│  ████████████░░░░░░░░  8 / 15                       │
├─────────────────────────────────────────────────────┤
│                                                     │
│         ┌─────────────────────────────┐            │
│         │                             │            │
│         │   ls -la                    │            │
│         │                             │            │
│         │   [スペース / クリックで    │            │
│         │       裏返す]               │            │
│         │                             │            │
│         └─────────────────────────────┘            │
│                    ↓ めくると                       │
│         ┌─────────────────────────────┐            │
│         │ ファイルとディレクトリの    │            │
│         │ 詳細一覧を表示するコマンド。│            │
│         │ -l: 詳細表示               │            │
│         │ -a: 隠しファイルも表示      │            │
│         └─────────────────────────────┘            │
│                                                     │
│   [← もう一度]              [覚えた →]             │
└─────────────────────────────────────────────────────┘
```

**操作**
- `スペースキー` or カードクリック → 表裏切り替え
- `←キー` or `[もう一度]` → 未習得に仕分け（デッキ末尾に戻す）
- `→キー` or `[覚えた]` → 習得済みに仕分け（次のカードへ）
- 全カード完了 → 完了画面（未習得カードが残っていれば再挑戦を促す）
- `[× 終了]` → フラッシュカード一覧へ

### 4. フラッシュカード作成・編集 `/flashcards/new` `/flashcards/[id]/edit`

**目的**: カードの登録・修正

```
┌─────────────────────────────────────────────────────┐
│  カード作成                                         │
├─────────────────────────────────────────────────────┤
│  資格  [LPIC-1 ▼]   分野  [ファイル操作 ▼]         │
├─────────────────────────────────────────────────────┤
│  表面（用語・コマンド）                             │
│  ┌─────────────────────────────────────────────┐   │
│  │ ls -la                                      │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  裏面（説明・解説）                                 │
│  ┌─────────────────────────────────────────────┐   │
│  │ ファイルとディレクトリの詳細一覧を表示する   │   │
│  │ コマンド。-l で詳細、-a で隠しファイルも表示 │   │
│  └─────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────┤
│              [キャンセル]  [保存]                   │
└─────────────────────────────────────────────────────┘
```

**操作**
- `[保存]` → バリデーション後、一覧へ戻る
- `[キャンセル]` → 一覧へ戻る（変更破棄）
- 編集画面では `[削除]` ボタンも表示（確認ダイアログ付き）

### 5. 問題集一覧 `/quiz`

**目的**: 問題の絞り込みと出題開始

```
┌─────────────────────────────────────────────────────┐
│  問題集                               [+ 新規作成]  │
├─────────────────────────────────────────────────────┤
│  [LPIC-1] [LPIC-2] [応用情報]                       │
│  分野 [すべて ▼]   タグ [________]  [検索]          │
├──────────────────────────────────────┬──────────────┤
│  問題文                              │ 分野   正答率│
│  ──────────────────────────────────────────────    │
│  ✓ ls コマンドの説明として正しいのは │ファイル  80%│
│  ✗ プロセスを終了させるコマンドは…  │プロセス  40%│
│  ─ chmod の説明として正しいのは…    │ファイル   ─ │
│                                      │             │
│  ✓:正解経験あり ✗:不正解あり ─:未挑戦             │
├─────────────────────────────────────────────────────┤
│  絞り込み結果: 32問                                 │
│       [1問ずつ出題]    [まとめて出題（全32問）]      │
└─────────────────────────────────────────────────────┘
```

**操作**
- 資格タブ・分野・タグで絞り込み → リアルタイムに問題数更新
- `[1問ずつ出題]` → 出題画面へ（解答後に解説表示）
- `[まとめて出題]` → 出題画面へ（全問解答後にまとめて解説）
- `[+ 新規作成]` → 問題作成画面へ
- 問題行クリック → 問題編集画面へ

### 6. 問題出題 `/quiz/study`

**目的**: 問題を解いてフィードバックを受ける

```
┌─────────────────────────────────────────────────────┐
│  LPIC-1 > ファイル操作          [× 終了]           │
│  問題 5 / 32                                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ls コマンドのオプションとして正しい説明はどれか。  │
│  （1つ選択）                                        │
│                                                     │
│  ○ A.  -l でファイルサイズのみ表示する             │
│  ● B.  -l でファイルの詳細情報を一覧表示する       │
│  ○ C.  -a でファイルを昇順に並べる                 │
│  ○ D.  -r でサブディレクトリを再帰的に削除する     │
│                                                     │
│                          [解答する]                 │
├─────────────────────────────────────────────────────┤
│  ※解答後に解説が表示される                         │
│                                                     │
│  ✅ 正解！                                          │
│  解説: ls -l は long format を意味し、パーミッション│
│  オーナー、サイズ、更新日時などを一覧表示します。   │
│                                                     │
│                          [次の問題 →]               │
└─────────────────────────────────────────────────────┘
```

**操作**
- 選択肢をクリックして選択（複数選択問題はチェックボックス）
- `[解答する]` → 正誤判定 + 解説表示
- `[次の問題 →]` or `→キー` → 次の問題へ
- `[× 終了]` → 問題集一覧へ（途中終了の確認ダイアログ）

### 7. 問題作成・編集 `/quiz/new` `/quiz/[id]/edit`

**目的**: 問題の登録・修正

```
┌─────────────────────────────────────────────────────┐
│  問題作成                                           │
├─────────────────────────────────────────────────────┤
│  資格 [LPIC-1 ▼]  分野 [ファイル操作 ▼]  タグ [  ] │
├─────────────────────────────────────────────────────┤
│  問題文                                             │
│  ┌─────────────────────────────────────────────┐   │
│  │ ls コマンドのオプションとして正しいのはどれか│   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  選択肢（正解にチェック）          複数選択 [ ]     │
│  ☐ [A. -l でファイルサイズのみ表示する        ] [×]│
│  ☑ [B. -l でファイルの詳細情報を一覧表示する  ] [×]│
│  ☐ [C. -a でファイルを昇順に並べる            ] [×]│
│  ☐ [D. -r でサブディレクトリを再帰的に削除する] [×]│
│  [+ 選択肢を追加]                                   │
│                                                     │
│  解説                                               │
│  ┌─────────────────────────────────────────────┐   │
│  │ ls -l は long format を意味し...            │   │
│  └─────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────┤
│              [キャンセル]  [保存]                   │
└─────────────────────────────────────────────────────┘
```

**操作**
- 選択肢のチェックボックスで正解をマーク
- `複数選択` トグル ON → チェックボックスが複数選択可能に
- `[+ 選択肢を追加]` → 選択肢行を動的追加（最大6つ）
- `[×]` → 選択肢を削除
- `[保存]` → バリデーション後、一覧へ戻る
- 編集画面では `[削除]` ボタンも表示

### 8. 模擬試験設定 `/exam`

**目的**: 試験の構成（分野別出題数・時間）を設定して開始

```
┌─────────────────────────────────────────────────────┐
│  模擬試験設定                                       │
├─────────────────────────────────────────────────────┤
│  資格  [LPIC-1 ▼]                                   │
├─────────────────────────────────────────────────────┤
│  分野別出題数                   利用可能問題数      │
│  ─────────────────────────────────────────────     │
│  ファイル操作      [  5  ] 問       32問            │
│  プロセス管理      [  5  ] 問       18問            │
│  ネットワーク設定  [ 10  ] 問       24問            │
│  テキスト処理      [  5  ] 問       12問            │
│  シェルスクリプト  [  5  ] 問        9問            │
│  ─────────────────────────────────────────────     │
│  合計              [ 30  ] 問                       │
├─────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────┤
│                     [試験を開始する]                │
```

### 9. 模擬試験中 `/exam/session`

**目的**: 本番に近い環境で問題を解く（解説なし）

```
┌─────────────────────────────────────────────────────┐
│  LPIC-1 模擬試験    残り時間: 45:32    [試験終了]   │
├─────────────────┬───────────────────────────────────┤
│ 問題番号        │                                   │
│ ┌─┐┌─┐┌─┐┌─┐  │  問題 5 / 30                      │
│ │1││2││3││4│  │                                   │
│ └─┘└─┘└─┘└─┘  │  ls コマンドの説明として           │
│ ┌─┐┌─┐┌─┐┌─┐  │  正しいのはどれか。               │
│ │5││6││7││8│  │                                   │
│ └─┘└─┘└─┘└─┘  │  ○ A. ...                         │
│ ...             │  ● B. ...                         │
│                 │  ○ C. ...                         │
│ 凡例:           │  ○ D. ...                         │
│ □ 未回答        │                                   │
│ ■ 回答済み      │         [← 前の問題] [次の問題 →] │
│ ★ フラグ        │                                   │
└─────────────────┴───────────────────────────────────┘
```

**操作**
- 左の問題番号パネルで任意の問題にジャンプ
- `★` フラグで後から見直す問題をマーク
- `[試験終了]` → 未回答問題があれば確認ダイアログ → 結果画面へ
- 制限時間0 → 自動的に試験終了

## 画面遷移図

```
ダッシュボード
    ├── フラッシュカード一覧
    │       ├── 学習モード ──→ (完了) ──→ 一覧へ
    │       └── 作成・編集
    │
    ├── 問題集一覧
    │       ├── 出題画面 ──→ (完了) ──→ 一覧へ
    │       └── 作成・編集
    │
    ├── 模擬試験設定
    │       └── 試験中 ──→ 結果 ──→ 設定 or ダッシュボード
    │
    └── 進捗管理
            └── 苦手問題 ──→ 問題集出題画面
```
