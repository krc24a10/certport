# 資格勉強ウェブアプリ 要件定義書

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | certport |
| 目的 | 資格の学習を効率化するウェブアプリ |
| 対象ユーザー | 自分（シングルユーザー） |
| 対象デバイス | PC（初期リリース） |

---

## 2. 対象資格

- **LPIC**（Linux技術者認定試験）Level 1 / Level 2
- **応用情報技術者試験**（午前問題中心）

---

## 3. 機能要件

### 優先度 High（初期リリース）

#### 3.1 フラッシュカード

- カード表面：用語・コマンド・概念
- カード裏面：説明・解説・使用例
- カードをクリック/スペースキーで表裏切り替え
- 「覚えた / もう一度」で仕分け（結果はログ保存しない、セッション中のみ）
- 資格・分野でカードをグループ分け
- カードの新規作成・編集・削除

#### 3.2 問題集・クイズ

- 4択選択式（複数選択にも対応）
- 問題文・選択肢・正解・解説を登録
- 資格・分野・タグで絞り込み
- 1問ずつ or まとめて出題モードを選択
- 解答後に即時フィードバック（正解/不正解 + 解説表示）
- 問題の新規作成・編集・削除

### 優先度 Medium（第2フェーズ）

#### 3.3 模擬試験

- **分野ごとに出題数を指定**して試験を構成（例：ファイル操作5問、ネットワーク3問）
- 時間制限を設定して開始
- タイマー表示（残り時間）
- 試験中は解説非表示
- 終了後にスコア・正答率を表示（分野別の内訳も表示）
- 間違えた問題の一覧表示

#### 3.4 進捗管理

- 学習履歴（日付・学習時間・問題数・正答率）
- 資格・分野ごとの習熟度グラフ
- 苦手問題リスト（正答率の低い問題を自動抽出）
- 連続学習日数（ストリーク）

### 優先度 Low（将来検討）

- スペースドリピティション（復習タイミングの自動スケジュール）
- CSV/JSONインポート・エクスポート
- スマートフォン対応

---

## 4. 非機能要件

| 項目 | 内容 |
|------|------|
| 認証 | 不要（シングルユーザー、ローカル利用） |
| パフォーマンス | 問題・カードの読み込みは1秒以内 |
| データ永続化 | DBで保存（SQLite + Prisma） |
| UI | シンプル・クリーン、学習に集中できるデザイン |
| アクセシビリティ | キーボード操作対応（フラッシュカードのめくり等） |

---

## 5. 画面一覧

```
/ (ダッシュボード)
  └── 最近の学習履歴・ショートカット

/flashcards
  ├── /flashcards             # 一覧・資格/分野選択
  ├── /flashcards/study       # 学習モード（カードめくり）
  └── /flashcards/edit        # 作成・編集

/quiz
  ├── /quiz                   # 一覧・絞り込み設定
  ├── /quiz/study             # 出題画面
  └── /quiz/edit              # 作成・編集

/exam
  ├── /exam                   # 設定画面（問題数・時間）
  ├── /exam/session           # 試験中画面
  └── /exam/result            # 結果画面

/progress                     # 進捗ダッシュボード
```

## 6. データモデル（概要）

### Certification（資格）
| フィールド | 型 | 説明 |
|---|---|---|
| id | Int | PK |
| name | String | 例: "LPIC-1", "応用情報" |

### Category（分野）
| フィールド | 型 | 説明 |
|---|---|---|
| id | Int | PK |
| name | String | 例: "ファイル操作", "データベース" |
| certificationId | Int | FK |

### Flashcard（フラッシュカード）
| フィールド | 型 | 説明 |
|---|---|---|
| id | Int | PK |
| front | String | 表面（用語・コマンド） |
| back | String | 裏面（説明） |
| categoryId | Int | FK |
| createdAt | DateTime | 作成日時 |

### Question（問題）
| フィールド | 型 | 説明 |
|---|---|---|
| id | Int | PK |
| body | String | 問題文 |
| choices | Json | 選択肢の配列 |
| correctAnswers | Json | 正解のインデックス配列 |
| explanation | String? | 解説 |
| categoryId | Int | FK |
| tags | String? | カンマ区切りタグ |

### StudyLog（学習ログ）
| フィールド | 型 | 説明 |
|---|---|---|
| id | Int | PK |
| type | Enum | FLASHCARD / QUIZ / EXAM |
| totalCount | Int | 出題数 |
| correctCount | Int | 正解数 |
| durationSec | Int | 学習時間（秒） |
| studiedAt | DateTime | 学習日時 |
| certificationId | Int | FK |

## 7. 技術スタック

| 役割 | 採用技術 |
|------|----------|
| フレームワーク | Next.js 15 (App Router) |
| 言語 | TypeScript |
| DB | SQLite |
| ORM | Prisma |
| UI | TailwindCSS + shadcn/ui |
| 状態管理 | React の useState / Server Actions 中心 |
| 認証 | なし（シングルユーザー） |

---

## 8. 開発フェーズ

| フェーズ | 内容 |
|----------|------|
| Phase 1 | プロジェクトセットアップ・DBスキーマ・共通レイアウト |
| Phase 2 | フラッシュカード（CRUD + 学習モード） |
| Phase 3 | 問題集・クイズ（CRUD + 出題モード） |
| Phase 4 | 模擬試験 |
| Phase 5 | 進捗管理ダッシュボード |
